# Air Hockey 3D

A 3D air hockey game for the browser, against the computer, a friend on the same device, or a
friend online with voice and video. It shares its interface, online play and tooling with the
author's Pool and Grandmaster 3D.

Work in progress: the table, the game and this description follow.

## Running it

```
npm ci
npm run dev          # the development server
npm run build        # type-check and build the site into dist/
npm test             # unit and architecture tests
npm run lint
npm run format:check
```
